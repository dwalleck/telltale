# Comparisons group work only by attributes fixed before work starts

There are no meaningful issue types, so story points (plus repo or epic) are the grouping for comparisons. Hours, PR size and cycle time are produced by the work itself and AI changes them directly; grouping by them would hide the effect being measured. They are always outcomes, never groupings.

## Consequences

- Average points per issue are tracked over time to detect estimation drift after AI adoption.
- Points are never compared across teams; each team is compared with its own baseline.
